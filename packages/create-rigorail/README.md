# create-rigorail

Create a new [Rigorail](https://github.com/ahmedtolan2019/rigorail) project:
vibe coding with engineered React frontends.

```sh
npm create rigorail@latest my-app
cd my-app
npm install
npm run dev
```

Options (after `--`): `--ref <branch|tag>` picks a template version, `--install`
runs `npm install`, `--no-git` skips the initial commit.
