# Launch brief: name, copy and earning plan

Agreed by Claude and Codex (gpt-6-astra) over five rounds on 2026-11-06. The
audience is all developers worldwide; the copy uses vibe coding, engineering, real
engineers and engineered frontends, and says "localization with RTL support".

## Name

**Rigorail**: *Vibe coding. Engineered frontends.*

- Story: engineering rigor plus rails that guide developers and AI agents through
  complex frontend work.
- Availability checked on 2026-11-06: npm `rigorail` and `create-rigorail` free,
  GitHub user/org `rigorail` free, `rigorail.com` shows no WHOIS registration, and
  no exact product match was found. A trademark search is still advised.
- Note: it loosely resembles Rigour, an AI code-quality tool; different name and
  product, but be aware of it.

### How we got here

| Round | Outcome |

## Copy

**Hero:** We engineered your vibe coding.

**Lines to use:** Make your AI coding agents work like real frontend engineers. ·
No more AI spaghetti slop in the long run. · Vibe code the screens. Keep the
engineering.

**Sub-line:** A React frontend template that gives developers and AI agents
modular architecture, working enterprise screens, and automated engineering
checks. Connect your own backend through an agreed API contract.

**Why it exists:** Vibe coding makes it easy to get a screen working. Complex
applications also need the engineering real engineers do: boundaries, contracts,
failure handling and verified behavior. Rigorail puts that work into the starting
point, with patterns to follow and checks that catch specific mistakes.

**GitHub description:** We engineered your vibe coding. A React frontend template
that makes AI coding agents work like real frontend engineers: modular
architecture, 40+ enterprise screens, automated checks that keep AI spaghetti slop
out, and localization with RTL support. Frontend only.

**GitHub topics:** `react`, `typescript`, `vite`, `tailwindcss`, `shadcn-ui`,
`frontend-template`, `ai-agents`, `vibe-coding`, `enterprise`, `rtl`

**npm (`create-rigorail`):** Create a Rigorail project: vibe coding with engineered
React frontends for developers and AI coding agents.

**Social one-liner:** Vibe code the screens. Keep the engineering. Meet Rigorail,
a React frontend template built for AI coding agents and the developers who
review their work.

## Earning from it

The code is MIT under Ahmed Tolan's copyright: anyone may use it, and you keep the
copyright. Sell what you add on top.

1. **Days 1-30:** publish the core (the funnel) and sell onboarding: turn a team's
   API contract into its first reviewed frontend workflow.
2. **Days 31-90:** pre-sell one Pro pack (for example procurement or inventory
   screens) under a commercial license in a separate private repository.
3. **After day 90:** expand from paid demand; fixed update periods, no unlimited
   support. GitHub Sponsors (already linked in `.github/FUNDING.yml`) is a bonus.

**First offer to test:** a US$1,500 fixed-price pilot for one list → detail →
approval workflow on an existing documented API, with agent setup, localization
with RTL support, focused browser tests and a recorded handoff. A starting point to
validate, not observed demand.
