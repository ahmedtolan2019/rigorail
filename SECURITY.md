# Security policy

Rigorail is a frontend template. Security of a deployed app also depends on its
backend, hosting and configuration (see [deployment](docs/deployment.md)).

## Reporting a vulnerability

Report privately through
[GitHub security advisories](https://github.com/ahmedtolan2019/rigorail/security/advisories/new).
Do not open a public issue. Include the affected file or flow, steps to reproduce
and the impact. You will get an acknowledgment, and fixes are released as soon as
practical, with credit if you want it.

## Supported versions

The latest release on `main` receives fixes. Projects created from the template
own their copy; apply relevant fixes from the changelog of the template.

## Scope

In scope: code in this repository (for example token or secret handling, unsafe
rendering, redirect validation, dependency advisories). Out of scope: your backend,
identity provider and hosting configuration.
